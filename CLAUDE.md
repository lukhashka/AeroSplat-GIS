# AeroSplat-GIS — нотатки для агентів
  
  * **Після кожного плану** — запис у приватному журналі (поза git): помилки, рішення, чому саме
    так, альтернативи, припущення, відкрите. Шлях — `AEROSPLAT_PRIVATE_DOCS` або
    `..\AeroSplat-GIS-private\docs\journal` поруч із репозиторієм. Репозиторій **публічний**:
    внутрішні документи (домен, клієнти, журнали, звіти сесій, внутрішні рішення) — лише там.
  * Висока надійність понад швидкість фіч (внутрішні вимоги надійності — у приватній теці).
  * Документація — українською; код і коментарі — англійською.
  * Перевірки: `venv\Scripts\python -m ruff check src tests tools`,
    `venv\Scripts\python -m pytest -q` (GPU/SITL-тести — маркерами), `npm test` і
    `npm run build` у `web/app`.
