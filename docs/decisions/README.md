# Architecture Decision Records

Раніше «чому так» жило в довгих коментарях-журналах у коді (`review §A3`,
`review-2 §S1` …), які посилалися на документи, що не потрапили в репозиторій
(`AeroSplat-viewer-review.md`, `PIPELINE.md`, `DIAGNOSTICS-WIRING.md`). Тепер
обґрунтування зібрано тут; у коді лишились короткі коментарі з посиланням на
ADR або на ідентифікатор `§…` з таблиці нижче.

| ADR | Тема |
|---|---|
| [0001](0001-server-viewer-transform-split.md) | Сервер лише центрує; поворот і масштаб — у в'ювері; єдиний кадр сцени |
| [0002](0002-trainer-activation-contract.md) | Контракт активацій `.pt`: оголошує виробник, а не евристика *(доповнення 2026-10-15: SH, `rgb` = DC)* |
| [0003](0003-splat-wire-format.md) | Формат передачі сплатів = GPU-текстура; ліміт адресації fp32 |

| [0006](0006-project-site-epoch-capture.md) | *(запропоновано; поправка 2026-10-15)* Project → Site → Epoch → Capture; фіксований Site ENU; авторські дані окремо від похідних; Earth Studio — реконструкція у сферичному ENU, продукти → WGS84 |
