# ADR-0002: Контракт активацій `.pt` оголошує виробник

**Статус:** прийнято · **Мітки:** §A4, §S1

## Контекст

Різні виходи тренера зберігають `scale` у log-просторі та `opacity` як logit,
або вже активовані значення. Перша версія вгадувала це з даних (log-scale
суб-одиничних гаусіанів від'ємні; logit виходить за [0,1]). Евристика мовчки
ламається: одиниці COLMAP довільні, тож для великої сцени всі log-scale можуть
бути додатними → «вже метричні» → `exp()` пропущено → сплати в ~100× менші,
opacity → 0, екран темний, у логу «успіх».

## Рішення

`.pt` несе ключ `activations: {scale_is_log, opacity_is_logit}`. Тренер
(`gs_trainer_v3._save`) пише обидва `False` (значення вже активовані).
`_activate_splat` читає контракт; евристика лишається лише як **гучний**
fallback для старих файлів, а в `scene-meta.activations` видно, звідки взято
рішення. `SPLAT_ACTIVATION_OVERRIDES` — тільки для відомо-поганого файлу. Після
активації перевіряються післяумови (`scale > 0`, opacity у (0,1)).
