# ADR-0002: Контракт активацій `.pt` оголошує виробник

**Статус:** прийнято · **Мітки:** §A4, §S1

## Контекст

Різні виходи тренера зберігають `scale` у log-просторі та `opacity` як logit,
або вже активовані значення. Перша версія вгадувала це з даних (log-scale
суб-одиничних гаусіанів від'ємні; logit виходить за [0,1]). Евристика мовчки
ламається: одиниці COLMAP довільні, тож для великої сцени всі log-scale можуть
бути додатними → «вже метричні» → `exp()` пропущено → сплати в ~100× менші,
opacity → 0, екран темний, у логу «успіх».

## Рішення

`.pt` несе ключ `activations: {scale_is_log, opacity_is_logit}`. Тренер
(`gs_trainer_v3._save`) пише обидва `False` (значення вже активовані).
`_activate_splat` читає контракт; евристика лишається лише як **гучний**
fallback для старих файлів, а в `scene-meta.activations` видно, звідки взято
рішення. `SPLAT_ACTIVATION_OVERRIDES` — тільки для відомо-поганого файлу. Після
активації перевіряються післяумови (`scale > 0`, opacity у (0,1)).

## Доповнення 2026-10-15: SH і gsplat-тренер (Фаза 2.2)

`rasterizer: gsplat` (`aerosplat/gs/gsplat_backend.py`) тренує колір як сферичні
гармоніки до 3-го ступеня. Сервер і в'ювер SH не обчислюють, тож контракт
розширено так, щоб старі споживачі не помітили різниці:

* `xyz`, `scale`, `rotation`, `opacity`, `activations` — як і раніше (активовані,
  обидва прапорці `False`).
* `rgb` = `clamp(0.5 + C0·sh[:, 0], 0, 1)` — DC-складова SH як колір, без
  залежності від ракурсу. Саме її показує в'ювер.
* `sh` — `(N, (d+1)², 3)` сирі коефіцієнти разом із DC, у конвенції Inria/gsplat:
  колір уздовж напрямку `d` (від центра камери до центра гаусіана) дорівнює
  `max(0, 0.5 + Σ sh_k·Y_k(d))`. Обчислення — `aerosplat/gs/sh.py`.
* `sh_degree` — `d`.
* `render` = `{rasterizer: "gsplat", rasterize_mode: "classic"|"antialiased"}` —
  як рендерили під час тренування. Стадія `eval` з `rasterizer=gsplat` бере
  `rasterize_mode` звідси; для `antialiased` непрозорість навчена з компенсацією
  Mip-Splatting, і в'ювер вмикає її лише тоді (ADR-0004, доповнення 2026-10-15).
  Inria/torch-тренер пише `{rasterizer: "cuda"|"torch", rasterize_mode: "classic"}`;
  файл без `render` читається як classic.
* `appearance` (лише `appearance=exposure`) — афінні корекції кольору train-кадрів;
  до сплата не застосовуються.

Стадія `georef` обертає `sh` разом із кадром (обертальна частина полярного
розкладу A). DC і `rgb` від обертання не залежать.
