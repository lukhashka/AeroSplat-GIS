# ADR-0004: Коректність шейдера splat

**Статус:** прийнято · **Мітки:** §A1, §A2, §B2, §B3, §C2, §3.5

* **§A1** `mat3(...)` у GLSL — column-major; `quatToMat` будував Rᵀ, тож усі
  несферичні гаусіани були повернуті назад. Виправлено; CPU-дзеркало в
  `aero-debug.js` ловить регресію.
* **§A2** `gl_PointCoord` — y-вниз, а Σ' виведена y-вгору, що перевертало
  мішаний член Махаланобіса. Instanced-квад передає `vDelta` у тому ж y-вгору
  просторі, тож проблема структурно відсутня.
* **§B2** Проєктована позиція кліпується до фрустума до побудови якобіана — без
  «вибухаючих» еліпсів на краях.
* **§B3** `gl.POINTS` замінено на instanced-квади: немає відсікання спрайта
  цілком, немає ліміту `ALIASED_POINT_SIZE_RANGE`, квад вписано в власний базис
  еліпса.
* **§C2** Компенсація непрозорості Mip-Splatting для 0.3-px дилатації.
* **§3.5** Захищені пошуки HUD, pixel ratio при resize, supersampling замість
  MSAA, `highp` у dense-фрагментному шейдері.
