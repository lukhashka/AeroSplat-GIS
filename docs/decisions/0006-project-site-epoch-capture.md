# ADR-0006: Project → Site → Epoch → Capture; авторські дані окремо від похідних

**Статус:** запропоновано (2026-10-15) · **Див.:** [TARGET_ARCHITECTURE §4, §5, §7](../TARGET_ARCHITECTURE.md)

## Контекст

Зараз одиниця роботи — «датасет»: одна папка кадрів, один ENU-початок
(середнє координат кадрів), одна сцена. Нові вимоги:

* одну ділянку знімають **з кількох джерел** (Earth Studio, дрон, ручна
  зйомка, інтернет) у різний час;
* для повеней потрібні **стани в часі** («до» і «після»);
* людина розмічає й підтверджує вікна, і перезапуск пайплайна не має цю
  роботу стирати або зсувати.

## Рішення

1. Ієрархія **Project → Site → Epoch → Run**, а **Capture** (партія кадрів
   одного джерела) належить Site і використовується в будь-якій епосі.
2. **Site ENU-початок фіксується при створенні Site** (точка на карті) і
   більше не змінюється. Нові захоплення не зсувають систему координат.
3. Внутрішня модель Землі — **WGS84**. Адаптер Earth Studio переводить
   сферичні координати в WGS84 на вході й записує похибку переходу у звіт.
4. **Run-директорії містять лише похідні дані** і можуть бути видалені й
   перераховані. Авторські дані (підтверджені Feature, цілі, аудит) лежать
   у `sites/<site>/authored/`.
5. Після нового run авторські Feature **переякорюються** similarity-
   трансформацією за спільними кадрами. Якщо залишок більший за поріг,
   Feature переходить у `stale`, а не зсувається мовчки.
6. Каталог зберігається в SQLite (SQLAlchemy/SQLModel + Alembic), великі
   дані — у файлах. На PostgreSQL+PostGIS переходимо, коли з'явиться кілька
   користувачів.

## Альтернативи

* *Лишити «датасет» і додати підпапки* — не розв'язує спільної системи
  координат і стабільності розмітки.
* *Зберігати розмітку в run* — кожен перезапуск втрачає або дублює роботу людини.
* *Одразу PostGIS* — зайва інфраструктура для однієї робочої станції.

## Наслідки

* `RunLayout` стає видом на новий layout; потрібен скрипт міграції `dataset_v6`.
* `DATASET_PATHS` у сервері замінюється читанням каталогу.
* `earthstudio_to_colmap` більше не обирає ENU-початок сам, а отримує його від Site.
